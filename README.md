# Claude Scheduler

Отложенные сообщения в сессии Claude Code для VS Code. Главный сценарий: упёрлись в лимит →
запланировали «продолжай» → в нужное время сессия сама продолжит задачу.

> Неофициальное расширение, с Anthropic не связано. Нужно установленное расширение Claude Code.

## Как пользоваться

- Кнопка ⏰ в заголовке вкладки Claude (или в его боковой панели, или в «Claude: отложенные» в Проводнике).
- Отметить одну или несколько сессий: одно сообщение уходит сразу в 10 сессий. Сессия открытой вкладки
  отмечена заранее, дальше идут 30 свежих сессий всех проектов. Все выбранные сессии стартуют параллельно.
- Время: `15:05`, `24.09 09:00`, `+30m`, `+2h` или пусто, то есть сразу. Если лимит ещё не
  сбросился, задание повторяется до сброса. Время сброса берётся из ответа, если его там нет, повтор идёт каждые `retryMinutes`.
- Текст (по умолчанию `claudeScheduler.defaultPrompt`).

Список в Проводнике → «Claude: отложенные»: ▶ отправить сейчас, 🗑 удалить или остановить, клик открывает сессию.
Удалить несколько: выделите с Ctrl/Shift и нажмите Delete (или правый клик → «Удалить»), либо кнопка
«Удалить несколько…» в заголовке списка открывает перечень с галочками.
В строке состояния видно, сколько сообщений ждёт и когда уйдёт ближайшее.

## Как это работает

В назначенное время выполняется `claude --resume <id> -p --output-format json --permission-mode <mode>`,
текст подаётся через stdin. ID сессии не меняется, ответ дописывается в тот же `.jsonl`.

Ограничения (API расширения Claude Code не даёт иначе):
- Сообщение не набирается в открытой панели: запуск идёт в фоне, вживую его не видно. После него кнопка
  «Открыть сессию» закрывает вкладку этой сессии (ищет её по заголовку) и открывает заново с диска.
  Если вкладку найти не удалось, закройте её и откройте сессию из истории сами.
- Не пишите в эту же сессию руками, пока идёт фоновый запуск: получится ветвление.
- В фоне некому подтвердить действие: всё, что `permissionMode` не разрешает, будет отклонено.
- Задания хранятся в globalStorage и переживают перезапуск. Если в назначенное время VS Code был закрыт,
  задание выполнится при следующем запуске. В нескольких окнах одно задание выполняется один раз:
  окна разыгрывают lock-файл.

## Установка

Через VS Code Marketplace (поиск «Claude Scheduler») или вручную: скачать `.vsix` из
[Releases](https://github.com/skiddgoddamn/claude-scheduler/releases) и выполнить
`code --install-extension claude-scheduler-<версия>.vsix`.

Сборка из исходников: `node test.js && npm run package`.
